# BSDSF24A010-OS-A01

A C utility library (libmyutils) implementing custom string and file functions, demonstrating:
- Multi-file compilation with Make
- Static (.a) and dynamic (.so) library builds
- Man page documentation and installation

See REPORT.md for detailed analysis of each build stage.

Build instructions:
Run "make" to build static and dynamic executables.
Run "sudo make install" to install the client program and man page system-wide.
